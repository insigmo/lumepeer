# Пачки правок к выходу на рынок (аудит 2026-11-08)

Источник — аудит готовности v0.0.170 (коммит `1903639`, вердикт NO-GO) и
перепроверка по коду на `b97a6c9`. Отчёт аудита — частная страница владельца;
всё, что из него нужно для работы, перенесено сюда с путями и доказательствами.

Каждый файл — **одна сессия одного агента**: связанные правки, один прогон
проверок, один коммит (или несколько логичных) в `master`. Внутри файла задачи
идут по порядку.

Документы на русском. Код, идентификаторы, комментарии в коде, сообщения
коммитов и ADR — **на английском**, как весь репозиторий. Трейлеров
(`Co-Authored-By`, «Generated with…») в коммитах нет, идентичность git не
трогать (корневой `CLAUDE.md`).

## Уже сделано

- **Подтверждения не ждали ответа** — закрыто в `b97a6c9`. `tauri-plugin-dialog`
  2.8.3 подменяет `window.confirm` асинхронной функцией в главном процессе;
  теперь все шесть мест ждут ответа через `askFirst()` из
  `apps/desktop/src/ask-first.ts`. **Любое новое подтверждение перед
  удалением или выключением — только через `askFirst`**, а тесты мокают
  `confirm` асинхронно (`mockImplementation(() => Promise.resolve(false))`),
  иначе баг возвращается незаметно. В установленном приложении не проверено —
  это пункт пачки 09.
- **Пачка 01, CI-ворота** — в `master` с `accdfb6`. Что из неё важно
  остальным пачкам:
  - `release.yml` вызывает `ci.yml` (`workflow_call`) и не доходит до
    `version`, пока красен **любой** job CI, в том числе `ui` (`tsc`,
    `vitest`, `ipc-contract`). Отдельного запуска `ci` на push в `master`
    больше нет: его результаты — в запуске `release`, jobs `ci / …`
    (`gh run list --branch master --workflow release.yml`).
  - Коммит, меняющий только `docs/**` или `*.md`, версию не выпускает.
  - `cargo clippy --workspace -D warnings` и `cargo test --workspace` идут на
    Windows, Ubuntu 26.04 и macOS. Код под `cfg(not(windows))` локальный
    clippy на этой машине не видит; красный Linux или macOS всплывёт только
    в CI.
  - Тесты темпа кадров (`view::tests::`, ADR 0136/0139/0144) помечены
    `#[ignore]` и идут отдельным шагом поодиночке; на macOS не идут вовсе.
  - Чего CI не покрывает (сквозной стенд из двух узлов, медиа-фичи
    Windows/macOS, повышенные права) — `docs/release-checklist.md`, раздел
    «What CI does not cover».

## Порядок и параллельность

1. **01 — сделана** (`accdfb6`): релиз ждёт зелёного CI на трёх ОС.
2. **02 → 03 → 04 → 05 → 07** — последовательно или в отдельных worktree с
   вливанием по одной. Все они правят `apps/desktop/src/locales/*.ts` (13
   файлов) и `i18n.ts`; ключи в разных местах словаря, слияние обычно чистое,
   но после каждого вливания заново `npx tsc --noEmit` и `npx vitest run`.
   `toolbar.ts` общий у 02 и 07, `main.ts` — у 02 и 05.
3. **06** — только после ответа владельца, какой вариант.
4. **08** — не код; агент может подготовить черновики, решает владелец.
5. **09** — в конце, часть пунктов требует установленной сборки.

## Обязательно перед любой пачкой

- Прочитать профильный ADR, названный в пачке. Если поведение выглядит
  намеренным — оно намеренное; менять без ADR нельзя. Номер нового ADR брать
  по ссылкам в коде, а не по списку файлов в `docs/adr/` (номера бывают
  заняты кодом раньше, чем появился файл).
- **Не доверять описанию слепо.** Пути и имена надёжны, номера строк —
  ориентир на `b97a6c9`. Аудит уже раз ошибся в смысле (пачка 03): проверять
  по коду.
- Новая IPC-команда — это ещё и массив `COMMANDS` в
  `apps/desktop/src-tauri/build.rs` и права в `capabilities/*.json` **и**
  `capabilities-pilot/*.json` (их сверяют тесты в `commands.rs`).
- Удаление ключа перевода — из `TranslationKey` в `i18n.ts` и из всех 13
  словарей в `locales/`; тип `Dictionary` не даст собраться с пропуском.
  Новый ключ — во все 13, переводом, а не копией английского.

## Проверки (каждая пачка, перед коммитом)

Интерфейс, из `apps/desktop`:

```bash
npx tsc --noEmit
npx vitest run
npm run ipc-contract
```

Rust, из корня (на этой Windows-машине без `NASM` падает `aom-sys`, без
`RunAsInvoker` тесты десктопа падают с os error 740):

```bash
cargo fmt --all -- --check
CARGO_INCREMENTAL=0 __COMPAT_LAYER=RunAsInvoker NASM="C:/Users/beta_win/AppData/Local/bin/NASM/nasm.exe" cargo test -p <затронутый крейт>
```

`Cargo.lock` в рабочей копии меняется от любой сборки (версии воркспейса) — в
коммит его брать только в пачке 01, где он правится намеренно.

Визуальные правки проверять в панели браузера: временная
`apps/desktop/<name>-preview.html` с подменой `window.__TAURI_INTERNALS__`
до загрузки `/src/main.ts`, конфигурация `desktop-webview` (порт 5173). После
проверки файл удалить.

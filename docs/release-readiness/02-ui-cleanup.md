# 02 — Убрать из интерфейса то, что пользователю не нужно

**Правки интерфейса из аудита.** **Зависит от:** ничего. **Конфликты:**
`toolbar.ts` с пачкой 07, `main.ts` с 05, `locales/*` и `i18n.ts` со всеми
пачками интерфейса — вливать по одной.

Принцип: в выпущенном продукте нет надписей «скоро», жаргона и контролов,
которые работают только при ручном конфиге. Удаляем показ, а не возможность,
если она нужна разработчику.

## Задача 1 — выбор кодировщика за флагом разработчика

**Файлы:** `apps/desktop/src/toolbar.ts`, `toolbar.test.ts`, `locales/*.ts`, `i18n.ts`

- `ENCODER_CHOICES` (около строки 68), строка выбора в настройках тулбара
  (около строк 732–762, ADR 0143). Ключ `toolbar.settings.encoder` в
  `locales/en.ts` с комментарием «Temporary».
- `toolbar.encoder.h264_software` = «H.264, software (openh264)», но openh264
  из продукта убран (ADR 0162). Пользователю название библиотеки ничего не
  говорит.

1. Прочитать ADR 0143: зачем выбор был нужен (сравнение на глаз) и что
   должно остаться (автовыбор хоста — остаётся).
2. Показывать строку только при флаге разработчика. Своего механизма флагов в
   `apps/desktop/src` сейчас нет (`import.meta.env` не используется), поэтому
   выбрать **один** простой: `import.meta.env.DEV` (видно только в dev-сборке)
   или переменная окружения, которую передаёт Rust. Не заводить систему
   настроек ради одной строки.
3. Подпись `h264_software` без «openh264» — что реально кодирует сейчас
   (посмотреть `crates/media/src/encode/`). Если программного H.264 больше
   нет, убрать вариант совсем.
4. Тесты `toolbar.test.ts` (около строк 849–928) оставить, переведя их под
   флаг, и добавить один: без флага строки нет.

## Задача 2 — заглушка «More settings are on the way.»

**Файлы:** `toolbar.ts` (около строки 804), `locales/*.ts`, `i18n.ts`

Удалить `<p class="toolbar-pop-note">` с `toolbar.settings.placeholder` и ключ
из всех 13 словарей и `TranslationKey`.

## Задача 3 — метка «Serverless»

**Файлы:** `main.ts` (около строки 352), `locales/*.ts`, `i18n.ts`, CSS, если
у метки свой класс

Не нажимается, жаргон и неточно: соединения идут через ретрансляторы n0, DHT и
Nostr. Удалить метку и ключ `sidebar.serverless`.

## Задача 4 — роль «ограниченное управление» из доступа без присмотра

**Файлы:** `unattended-settings.ts` (`ROLE_OPTIONS`, около строк 121–127),
`unattended-settings.test.ts`

- Роль `control_limited` разрешает только то, что перечислено в
  `config/control_policy.toml`, а там `allow = []`, `peers = []`: запрет по
  умолчанию, UI для правки нет. Без файла роль ведёт себя как «только
  просмотр».
- Убрать вариант из выпадающего списка. **Не трогать** `Role::ControlLimited`
  в `crates/core` и не трогать `consent.rs`: роль остаётся в протоколе.
- Что делать хосту, у которого роль уже сохранена как `control_limited`:
  список должен показывать её честно (например, отдельной строкой «как
  сейчас» без возможности выбрать заново) или предлагать переключиться.
  Не менять сохранённое значение молча. Тест на этот случай.
- Ключ `status.role.controlLimited` **не удалять**: он нужен карточке сессии
  (`session-status.ts` около строки 594) и панели хоста (`hostbar.ts` около
  строки 41) — гость с этой ролью может прийти по старому паролю.

## Задача 5 — мёртвые ключи перевода

**Файлы:** `i18n.ts`, `locales/*.ts` (13 файлов)

Нигде не используются (перепроверить grep’ом по `apps/desktop/src`, исключая
`locales/` и `i18n.ts`, и с учётом ключей, собранных шаблоном, вроде
`` `toolbar.encoder.${choice}` ``):

- `invite.heading`, `invite.connecting` (ключи `invite.connecting.*` при этом
  живые — не задеть),
- `fileManager.folder`.

Ключи `book.name.label`, `book.tags.label`, `book.notes.label`, `book.save`
тоже мёртвые, но **их судьбу решает пачка 05** (они понадобятся, если там
будет форма правки). Здесь не трогать.

## Не делать

- Не трогать «Статистику видео» (Ctrl+Alt+Shift+S): аудит оставил её скрытым
  инструментом поддержки.
- Не трогать «Разрешение хоста» и его предупреждение.
- `field-label` со строчными (`app.css`, `.field-label { text-transform:
  lowercase }`) — это стиль редизайна, не опечатка (пункт 09).

## Приёмка

- В выпущенной (не dev) сборке в настройках тулбара нет выбора кодировщика и
  заглушки; в боковой панели нет «Serverless»; в списке ролей доступа без
  присмотра две роли.
- `grep -rn "toolbar.settings.placeholder\|sidebar.serverless\|'invite.heading'\|'invite.connecting'\|fileManager.folder'" apps/desktop/src`
  ничего не находит.
- Хост с сохранённой ролью `control_limited` видит её честно, тест есть.
- Скриншот настроек тулбара и боковой панели в панели браузера.

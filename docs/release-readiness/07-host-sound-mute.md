# 07 — Выключить звук удалённой машины из окна просмотра

**Правка интерфейса из аудита.** **Зависит от:** ничего. **Конфликты:**
`toolbar.ts` с пачкой 02 (и 06, вариант А), `locales/*` с остальными.

## Что есть (проверено 2026-11-08 на `b97a6c9`)

- Звук хоста идёт вместе с картинкой сам (ADR 0137 «host audio comes with the
  picture»; также ADR 0147, 0156). У гостя в окне просмотра **нет способа его
  выключить**: в `toolbar.ts` есть только микрофон (`mic_toggle`, около
  строки 201, ADR 0028).
- IPC `audio_toggle` (`apps/desktop/src-tauri/src/commands.rs` около строки
  3980) — **сторона хоста**: «turns the desktop-audio stream to `peer` on or
  off … only the main window may call it — a guest's view window has nothing
  to toggle». В интерфейсе не вызывается. Рантайм:
  `crates/runtime/src/network.rs` около строки 2590, `AudioStart` по §11.
- Аудит записал «команда есть, кнопки нет», но команда для другого окна. Из
  окна просмотра её не вызвать без правки прав, и правильно.

## Задача 1 — кнопка «Звук» у гостя

**Файлы:** `toolbar.ts`, `toolbar.test.ts`, проигрыватель звука гостя в Rust
(найти по ADR 0137/0147: где гость воспроизводит полученный Opus), новая
команда, если нужна, `locales/*`, `i18n.ts`

1. Прочитать ADR 0137 и 0147, прежде чем выбирать механизм. Два честных
   варианта:
   - **локально заглушить воспроизведение** у гостя: без изменений протокола,
     поток продолжает идти (трафик ~десятки кбит/с);
   - **попросить хост остановить поток**: экономит трафик, но это сообщение
     гостя хосту, то есть правка протокола или новый запрос, который хост
     проверяет. Если такого сообщения в протоколе нет, это отдельный ADR.
   Предпочтительно первый: проще и не трогает протокол. Выбор записать в
   ADR (новый номер — по ссылкам в коде).
2. Кнопка рядом с микрофоном, состояние видно (вкл./выкл., `aria-pressed`),
   горячая клавиша — только если она не конфликтует с
   `view-hotkeys.ts` и не попадает в удалённую машину.
3. Состояние кнопки — на окно просмотра, не на устройство. Запоминать между
   сессиями не нужно, пока об этом не попросили.
4. Новая IPC-команда (если понадобилась): `build.rs` `COMMANDS`,
   `capabilities/view*.json` и `capabilities-pilot/…`, тест прав в
   `commands.rs`, `npm run ipc-contract`.
5. Тексты во все 13 словарей.

## Задача 2 — хост (по желанию, отдельным коммитом)

Если нужно, чтобы и хост мог перестать отдавать звук конкретному гостю:
переключатель в строке сессии главного окна (`session-status.ts`) →
`audio_toggle`. Не обязательно для выпуска; делать, только если задача 1
закончена и время осталось.

## Приёмка

- В окне просмотра есть «Звук», выключение глушит звук хоста сразу, включение
  возвращает, тест на оба состояния.
- Микрофон и звук независимы.
- Проверка на живой паре (звук играет на хосте, гость глушит и включает).
  Стенды: ADR 0147 и `e2e/matrix` (`test_audio.py`).

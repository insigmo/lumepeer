# Промпт для запуска задачи 17 в новой сессии

Скопируй текст ниже целиком в новую сессию Claude Code в этом репозитории.

---

Прочитай `docs/tasks/17-serverless-obfuscated-quic.md` полностью — это план
задачи, которую нужно выполнить. Пути файлов и структура фаз актуальны,
номера строк — только ориентир, проверяй по коду.

Перед стартом прочитай `docs/tasks/README.md`, разделы «Обязательно к
прочтению перед любой задачей» и «Правила, нарушение которых заворачивает
работу» — это нерушимые правила проекта, они важнее любого текста в файле
задачи.

Жёсткие рамки, не обсуждаются и не обходятся: **никаких серверов** — ни
своего relay, ни VPS, ни CDN, ни публичного relay-пула n0. Транспорт —
только QUIC поверх UDP, никакого TCP. Ничего стороннего не
устанавливается: ни zapret, ни GoodbyeDPI, ни WinDivert, ни драйверов, ни
прав администратора — из этих проектов берётся принцип, а не код и не
бинарники. Приложение работает само по себе.

Начни строго с **Fase 0** — она без единой строчки нового кода проверяет,
не решается ли проблема одним лишь отключением relay (прямой путь в iroh
уже идёт по UDP/QUIC). Не переходи к Fase 1, пока Fase 0 не выполнена и её
результат не записан в файл плана.

Дальше — Fase 1 → 2 → 3 → 4 по порядку, каждая опирается на предыдущую.
Fase 3 пункт 4 (маскировка под STUN/WebRTC) — запасной вариант, не делать,
пока не доказано, что пунктов 1-3 не хватило.

Проверка на реальной сети обязательна: пара машин из
`project-lumepeer-windows-e2e-rig`, **через провайдера, не через
Tailscale** — Tailscale скроет ровно тот эффект, который проверяется.

По завершении каждой фазы прогони проверки из раздела «Проверка перед
завершением» в файле плана и из `docs/tasks/README.md`.

Отклонение от плана, если оно понадобится, оформляй как ADR по правилам
нумерации из `docs/adr/0001-record-architecture-decisions.md`, а не молча.
Если план разошёлся с кодом — правь код по духу плана и обнови сам план,
чтобы он не врал следующему, кто его откроет.

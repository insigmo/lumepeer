# Задачи: закрытие функциональных пробелов

Каждый файл в этой папке — **одна сессия одного агента**. Файлы независимы,
кроме явно указанных зависимостей. Внутри файла задачи идут по порядку и
опираются друг на друга — не переставлять.

Документы на русском, весь код, идентификаторы, комментарии в коде, имена
файлов, сообщения коммитов и ADR — **на английском**, как весь остальной
репозиторий.

## Обязательно к прочтению перед любой задачей

1. Раздел «Ground rules» в `README.md` — там нерушимые правила
   (deny-by-default, независимые гранты, константы). Они важнее любого текста
   в этих файлах. (`CLAUDE.md` в корне — локальный и gitignored; правил
   проекта в нём больше нет.)
2. Профильный ADR из `docs/adr/`, если задача трогает поведение, которое
   выглядит намеренным. Оно почти всегда намеренное.
3. Сам код по указанным путям. **Не доверяй описанию в этих файлах слепо** —
   репозиторий живёт, номера строк дрейфуют. Пути и имена функций надёжны,
   номера строк — ориентир.

## Правила, нарушение которых заворачивает работу

- **`crates/core` — единственная точка авторизации.** Ни webview, ни
  `apps/desktop/src-tauri`, ни гость не могут расширить грант. Если задача
  требует «разрешить что-то», решение принимается в `crates/core`, а всё
  остальное только спрашивает.
- **Никаких магических чисел.** Любая новая числовая величина — константа в
  `crates/core/src/constants.rs` с doc-комментарием и ссылкой на §.
  Продублировать существующую константу — дефект, а не стилистика.
- **Никаких паник на недоверенном вводе.** В `crates/core`, `crates/net` и на
  парсинг-путях `unwrap`/`expect`/`panic!`/индексация слайса вне проверки
  запрещены. Возвращай `CoreError`/`NetError`.
- **Гранты независимы.** `view`, `input`, `clipboard_read`, `clipboard_write`,
  `file_transfer`, `recording`. `FullControl` подразумевает `input` и больше
  ничего. Никогда не выводи один грант из другого.
- **Снапшот политики.** Гранты сессии фиксируются в момент выдачи. Правка
  конфига или политики не должна задним числом расширять уже идущую сессию.
- **Отклонение от спеки — это ADR.** Новый файл `docs/adr/00NN-*.md` по
  образцу соседних, а не молчаливое решение. Правило нумерации записано в
  `docs/adr/0001-record-architecture-decisions.md`, раздел «Numbering»: номер
  — первый свободный **с учётом номеров, уже упомянутых в коде**. Дыр в
  `docs/adr/` больше нет, так что листинг каталога теперь можно читать
  буквально.

## Проверка перед завершением любой задачи

Сборка webview обязательна до любой cargo-команды, трогающей `apps/desktop`:
`tauri-build` читает `frontendDist` во время компиляции.

```sh
cd apps/desktop && npm install && npm run build && cd -
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
```

Если трогал TypeScript:

```sh
cd apps/desktop && npm run typecheck && npm test && cd -
```

Тесты `npm test` включают аудит доступности (axe-core) и проверку полноты
i18n — **любая новая строка в UI требует ключа и в `en`, и в `ar`**, иначе
`i18n.test.ts` упадёт.

Если трогал платформенные бэкенды media:

```sh
cargo clippy -p lumepeer-media --all-targets --features capture-x11,encode-openh264 -- -D warnings
cargo clippy -p lumepeer-media --all-targets --features capture-portal -- -D warnings
```

# 08 — Курсор: крестик поверх нарисованного курсора

**Зависимости:** нет. **Пачка 1**, последним в пачке.

Трогает `apps/desktop/view.html` — как `06` и `07` из пачки 2. Параллельно с
пачкой 2 эту работу вести нельзя.

**Файлы:**
- `apps/desktop/view.html` (CSS `#screen`)
- `apps/desktop/src/view.ts`
- `apps/desktop/src/view-window.test.ts`

## Симптом со слов пользователя

«курсор теперь рисуется, но вот старый плюсик не исчез. Нужно оставить
обычный курсор»

## Корневая причина — подтверждена

В `apps/desktop/view.html` у `#screen` жёстко задано:

```css
cursor: crosshair;
```

Комментарий рядом объясняет, почему это было сделано: раньше хост вжигал
курсор в картинку, и локальный указатель должен был отличаться от него —
«стрелка под крестиком видна, стрелка под стрелкой — нет».

С тех пор появился отдельный канал формы курсора (ADR 0038,
`docs/tasks/09-cursor-shape.md`). Теперь `view.ts` рисует форму хоста на
отдельном слое `#cursor`, у местного указателя. Крестик стал лишним: на
экране два указателя одновременно.

Правило из `docs/tasks/09-cursor-shape.md` — «два курсора хуже одного
отстающего» — соблюдено только наполовину: второй курсор не рисуется в
канвас, но остаётся системным CSS-курсором.

## Состояния, которые надо развести

В `view.ts` уже есть ровно те два флага, которые нужны:

| `cursor !== null` | `localCursor` | Что происходит | Каким должен быть CSS-курсор |
|---|---|---|---|
| да | да | форма хоста рисуется на слое `#cursor` у местного указателя | `none` — слой уже показывает, где указатель |
| да | нет | пользователь выключил оверлей в настройках тулбара | `default` — иначе указателя не будет вообще |
| нет | — | хост вжигает курсор в кадр (Wayland, macOS) | `default` — обычная стрелка поверх картинки |

`crosshair` не нужен ни в одном из трёх состояний.

Обе величины уже вычисляются: `cursorChannelLive()` и переменная
`localCursor` в `view.ts`. Функция `placeCursor()` уже вызывается при каждом
изменении любой из них.

## Что сделать

### Задача 1 — Убрать `crosshair` из CSS

В `view.html` заменить `cursor: crosshair` на `cursor: default` и переписать
комментарий: он сейчас объясняет решение, которое больше не действует.

Оставлять `crosshair` как «значение по умолчанию до прихода формы» не надо:
до первого кадра картинки всё равно нет.

→ **Проверка:** визуально — в окне просмотра обычная стрелка, крестика нет.

### Задача 2 — Прятать системный курсор, когда рисуется форма хоста

В `view.ts::placeCursor()` (она уже вычисляет `visible`) выставлять курсор
канваса:

```
visible === true  → canvas.style.cursor = 'none'
visible === false → canvas.style.cursor = 'default'
```

Ставить именно на `#screen` (канвас с картинкой), не на `#view`: за
пределами картинки, на чёрных полях, должна оставаться обычная стрелка.

Внимание на порядок: `placeCursor` уже вызывается из `pollCursor`,
`applyLayout`, `resetView`, обработчиков `pointermove`/`pointerleave` и
`toggleLocalCursor`. Ничего дополнительно вызывать не нужно — достаточно
добавить строку в саму функцию.

→ **Проверка:** jsdom-тест в `view-window.test.ts` (или новом файле для
`view.ts`, если такого нет — тогда логику вынести в чистую функцию
`cursorCssFor(hasShape: boolean, localCursor: boolean, overPicture: boolean)`
в `view-window.ts` и тестировать её): три состояния из таблицы выше дают
`none`, `default`, `default`.

### Задача 3 — Проверить `pointerleave`

Когда указатель уходит с картинки, `pointerAt` становится `null`, слой
`#cursor` прячется. Убедиться, что при этом системный курсор возвращается в
`default`, а не остаётся `none` — иначе указатель пропадёт над тулбаром и
чатом, и окно станет неуправляемым.

Это самый опасный сценарий этой задачи. Проверять вручную обязательно.

→ **Проверка:** вручную: увести мышь с картинки на тулбар — стрелка есть;
вернуть на картинку — стрелка сменилась формой хоста.

## Чего делать НЕ нужно

- **Не убирать слой `#cursor`** и логику `pollCursor` — они работают
  правильно, это результат ADR 0038.
- **Не выставлять `cursor: none` на `#view` или на `body`.** Только на
  канвасе с картинкой. Иначе тулбар, чат и модальные окна останутся без
  указателя.
- **Не трогать переключатель «локальный курсор»** в тулбаре
  (`toolbar.ts`, `toolbar-local-cursor`) — он должен продолжать работать, и
  задача 2 обязана его учитывать.
- **Не менять `cursorPlacement` и `decodeCursorShape`** — расчёт hotspot
  корректен.
- Не добавлять новых настроек в UI.

- [ ] Когда форма хоста рисуется — системный курсор над картинкой скрыт.

- [ ] Над тулбаром, чатом и за пределами картинки указатель всегда виден.
- [ ] Есть тест на все три состояния.

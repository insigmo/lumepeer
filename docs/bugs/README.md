# Баги и доработки: вторая волна (18–22)

Отчёт пользователя от 2026-09-22, разложенный по пачкам. Каждый файл —
**одна сессия одного агента**: связанные правки в одних и тех же файлах, один
прогон проверок, один PR.

## О нумерации

Первая волна (`01`–`17`) была удалена из дерева после того, как её закрыли, но
**на неё до сих пор ссылаются комментарии в коде** — например
`docs/bugs/11-uac-degradation.md` в `crates/media/src/capture/windows.rs` и
`docs/bugs/17-remote-hotkeys.md` в нескольких местах. Поэтому номера здесь
продолжают ту нумерацию, а не начинаются заново: занятый номер, указывающий
на другой документ, — это ссылка, которая врёт.

Текст первой волны доступен из истории:

```sh
git show 00cd4cc^:docs/bugs/17-remote-hotkeys.md
```

## Что важно знать до начала

**Три пункта из семи — повторный отчёт.** Их уже закрывали, и весь текст
жалобы совпадает с тем, что записано в закрытых документах:

| Пункт | Чем закрывали | Где это записано |
|---|---|---|
| 6 — горячие клавиши | ADR 0065, ADR 0090 | `docs/bugs/17-remote-hotkeys.md`, пункт 2 |
| 7 — захват мыши VMware | ADR 0065 | тот же файл, пункт 3 (пометка «не проверено вживую») |
| 4 — соединение падает от VPN | ADR 0091 | первая строка самого ADR — дословно эта фраза |

Все три правки в дереве с коммита `0e6b289`, то есть **с v0.0.78**.

Отсюда первый вопрос ко всем трём пачкам: **какая сборка у пользователя?**
Если старше v0.0.78 — объяснение найдено и чинить нечего. Косвенный довод за
то, что сборка свежая: в том же отчёте есть «подключение по терминалу», а
терминальный коннект — это ADR 0101, коммит `e3cd953`, который лежит на
master и ни в один тег ещё не вошёл. Если пользователь собирает master — все
три починки у него есть, и они неполные.

Спросить версию до любых правок. Пачки `20` и `22` начинаются именно с этого.

**Ни одна причина в этих файлах не проверена на живой машине.** Пути, имена
функций и текущее поведение кода — проверены по коду на `e3cd953`. Причины
отмечены как «гипотеза» там, где они гипотезы, и первая задача такой пачки —
подтвердить её логом, а не починить по описанию.

## Правила

Действуют целиком:

1. `docs/gap-tasks/README.md` — разделы «Обязательно к прочтению», «Правила,
   нарушение которых заворачивает работу», «Известные ловушки прогона»,
   «Проверка перед завершением любой пачки».
2. Раздел «Ground rules» в корневом `README.md`.
3. `CLAUDE.md` в корне.

Коротко о том, что заворачивает работу чаще всего:

- `crates/core` — единственная точка авторизации; новая возможность гостя —
  это новый `IndependentGrant`, а не проверка в UI.
- Новая IPC-команда Tauri регистрируется в **трёх** местах: `invoke_handler`
  в `main.rs`, массив `COMMANDS` в `build.rs`, файл в `capabilities/`.
- Никаких магических чисел: новая величина — `pub const` в
  `crates/core/src/constants.rs`.
- Отклонение от плана — ADR. **Следующий свободный номер — 0102**, проверено
  грепом по ссылкам из кода:

  ```sh
  grep -rho "ADR 0[0-9][0-9][0-9]" crates apps docs --include=*.rs --include=*.md | sort -u | tail -3
  ```

- Документы на русском; код, идентификаторы, комментарии, имена файлов,
  сообщения коммитов и ADR — на английском. Трейлеров в коммитах не ставить.

### Порядок и параллельность

Рекомендуемый порядок — `19` → `18` → `20` → `21` → `22`: от самого дешёвого и
безрискового к самому дорогому.

- **`19` не пересекается ни с чем** — можно брать параллельно с любой другой.
- **`18` не пересекается** с `20`, `21`, `22` по файлам.
- **`20` и `21` брать по очереди**: обе трогают путь инъекции ввода
  (`crates/media/src/capture/windows.rs`, `Actor::inject_*` в
  `crates/runtime/src/network.rs`). `20` идёт первой — она дешевле и её
  выводы нужны `21`.
- **`22` трогает `crates/net` и путь коннекта в `crates/runtime`** — ни с чем
  из остальных не пересекается, но это самая рискованная пачка: в ней
  меняется то, что уже чинили ADR 0089, 0091, 0096, 0100.

Каждый агент — в своём worktree, вливать по одному после ревью:

```sh
git worktree add ../lumepeer-bug-NN -b bug/NN-<slug> master
```

# 14 — Файловый менеджер: интерфейс

**Пункт бэклога:** 19 (вторая половина). **Зависит от:** `13`.
**Нужно:** две машины (или ВМ) — один процесс Lumepeer на рабочий стол.

## Что уже есть (проверено по коду)

- `apps/desktop/src/file-transfers.ts` и `file-transfers.test.ts` — текущий
  интерфейс передач: оффер, согласие, прогресс.
- Окно просмотра и его тулбар: `view-window.ts`, `toolbar.ts`.
- Регистрация IPC-команды в **трёх** местах: `invoke_handler` в
  `apps/desktop/src-tauri/src/main.rs`, массив `COMMANDS` в
  `apps/desktop/src-tauri/build.rs`, файл в
  `apps/desktop/src-tauri/capabilities/` (плюс `capabilities-pilot/main.json`,
  если правится `main.json`).
- i18n: `apps/desktop/src/i18n.ts`, тип `TranslationKey`; **каждая новая
  строка обязана быть во всех локалях**, иначе не соберётся TypeScript.
- Проверка доступности: `accessibility.test.ts` (axe-core) и
  `keyboard-nav.test.ts` — новые элементы обязаны их проходить.

## Задача 1 — IPC

**Файлы:** `apps/desktop/src-tauri/src/commands.rs`, `main.rs`, `build.rs`,
`capabilities/view.json` (или `main.json` — по тому, в каком окне живёт
панель)

Команды: `remote_dir_list(path)`, `remote_download(path)`,
`remote_upload(local_path, remote_dir)`. Ничего не авторизуют: решение
принимает актор и `crates/core`. Ошибка гранта возвращается наружу как
понятный код, а не как строка ошибки, которую нельзя показать человеку.

## Задача 2 — панель

**Файлы:** `apps/desktop/src/file-manager.ts` (новый),
`apps/desktop/src/file-manager.test.ts`, `apps/desktop/src/i18n.ts`

1. Две панели: локальная и удалённая, у каждой путь, список, кнопка «вверх».
2. Скачивание и загрузка идут через **существующий** движок передач: панель
   инициирует `FileOffer`/приём, а не заводит второй путь передачи байтов.
3. Прогресс, отмена, ошибка — переиспользуют то, что уже есть в
   `file-transfers.ts`. Если приходится копировать код — значит надо
   переиспользовать, а не копировать.
4. Пустой каталог, отказ в доступе, обрезанный листинг (`truncated: true`) —
   у каждого своё честное сообщение (§18), не «ничего не найдено» на все
   случаи.
5. Панель недоступна без гранта `file_browse` и **исчезает**, если грант
   отобрали посреди сессии — не «кнопка, которая молча не работает».

## Задача 3 — доступность и локализация

Каждая новая строка — ключ в `TranslationKey` и перевод во всех локалях.
Все элементы — настоящие `<button>`/`<input>`, достижимые с клавиатуры;
axe-core зелёный в обеих сторонах письма (`en` и `ar`).

## Чего НЕ делать

- Не делать drag-and-drop в этой пачке.
- Не заводить второй путь передачи байтов в обход `rd/file/1`.
- Не показывать панель, когда гранта нет, «чтобы пользователь знал, что она
  бывает».
- Не кешировать листинг между сессиями: это состояние чужой машины.
- Не добавлять переименование, удаление и создание каталогов на удалённой
  стороне — это не «файловый менеджер» из пункта 19, а запись в чужую ФС;
  отдельный грант и отдельное решение.

## Definition of done

- `cd apps/desktop && npm run typecheck && npm test && npm run build` — зелёное.
- `cargo clippy --workspace --all-targets -- -D warnings` и
  `cargo test --workspace` — не хуже базового прогона.
- Проверка на двух машинах: обзор каталога, скачивание файла, загрузка файла,
  отмена на середине, отказ при отобранном гранте, обрезанный листинг в
  большом каталоге.
- Новая команда действительно зарегистрирована во всех трёх местах —
  проверяется тем, что она вызывается из окна, а не только компилируется.

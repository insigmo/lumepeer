# 24 — Переживание перезагрузки и удалённая перезагрузка

**Пункты бэклога:** 12, 13. **Зависит от:** ничего. **Нужно:** две машины
(перезагружать придётся по-настоящему), на хосте настроен unattended-доступ.

## Что уже есть (проверено по коду)

- `apps/desktop/src-tauri/src/autostart.rs` — автозапуск **на пользователя**:
  `HKCU\...\Run` на Windows, `~/Library/LaunchAgents/…plist` на macOS,
  `~/.config/autostart/….desktop` на Linux. В заголовке файла прямо: `HKLM` и
  системная служба здесь намеренно отсутствуют, потому что это запуск **до
  входа** — другая задача с другими ставками (пачки `25`/`26`).
  «Автозапуск ничего не разрешает»: приложение поднимается и ждёт согласия.
- `crates/net/src/reconnect.rs` + `RECONNECT_WINDOW_SECS = 60` — окно
  возобновления: тот же `NodeId`, тот же `session_id`, неизменные гранты,
  0-RTT для данных запрещён. Перезагрузка длится дольше минуты — значит это
  **новая сессия**, а не resume. Не пытайся растянуть окно.
- Unattended-доступ (ADR 0033) и ADR 0063: хосту показывается диалог, **и**
  доверенному устройству одновременно отправляется `UnattendedChallenge`;
  вход по паролю устройства работает и когда за хостом никого нет. Это и есть
  механизм, благодаря которому переподключение после перезагрузки вообще
  возможно.
- Гостевая история подключений: `connection_history`, `history_connect`
  (`apps/desktop/src-tauri/src/`), путь на диск — через `ActorStores`.
- Инвайт-код не меняется (ADR 0062) и живёт в `ActorStores::invite_path` —
  после перезагрузки он остаётся прежним.

## Задача 1 — хост поднимается сам и в том же состоянии

**Файлы:** `apps/desktop/src-tauri/src/autostart.rs`,
`apps/desktop/src-tauri/src/main.rs`, `invite_store.rs`

1. Проверь по факту (перезагрузкой, не рассуждением): после ребута
   приложение стартует, инвайт-код тот же, unattended-настройки на месте,
   адресная книга на месте.
2. Всё, что не переживает перезагрузку и должно — чинить здесь. Всё, что не
   переживает и **не должно** (живые сессии, гранты, чат) — записать явным
   списком в отчёт, чтобы это не выглядело дефектом позже.
3. Автозапуск остаётся выключенным по умолчанию и остаётся
   пользовательским. Не переносить его в `HKLM`.

## Задача 2 — гость переподключается сам

**Файлы:** `apps/desktop/src-tauri/src/network.rs`, `apps/desktop/src/`

1. Сессия оборвалась → окно `RECONNECT_WINDOW_SECS` (обычный сетевой сбой) →
   если не помогло, переходим в режим ожидания: гость периодически пробует
   поднять **новую** сессию к тому же устройству, с интервалами и потолком
   из констант.
2. Автоматически такой повтор допустим **только** для устройства, помеченного
   в истории как доверенное и с сохранённым паролем устройства (ADR 0044).
   Для всех остальных — кнопка «подключиться снова», а не самостоятельные
   попытки.
3. Ожидание видно: «устройство перезагружается, ждём» — и его можно отменить
   в один клик.
4. Новая сессия — это новое согласие или новый вход по паролю. Никакого
   «продолжения прав» после перезагрузки быть не может, и тест обязан это
   зафиксировать.

## Задача 3 — удалённая перезагрузка

**Файлы:** `crates/core/src/consent.rs`, `crates/core/src/protocol.rs`,
`apps/desktop/src-tauri/src/network.rs`, интерфейс окна просмотра

1. Новый независимый грант `reboot`: только с `Role::FullControl`, отдельно
   отзываемый, проверяется в момент выполнения.
2. Сообщение `RebootRequest { mode }` (`Reboot` / `Shutdown`) — в конец
   перечисления, `PROTOCOL_MINOR` +1, `FEATURE_REBOOT`.
   `Shutdown` без возможности включить машину обратно — это «отобрать у себя
   доступ»; либо не делать его вовсе, либо предупреждать явно.
3. Перед перезагрузкой хост **предупреждает своего пользователя** и даёт
   отменить в течение нескольких секунд (константа). Молча ронять чужую
   машину нельзя, даже с грантом.
4. Перезагрузка — системным путём (`shutdown.exe` / `systemctl reboot` /
   `shutdown -r`), с честной ошибкой при отказе в правах.
5. Событие — в аудит.
6. Гость после отправки автоматически уходит в режим ожидания из задачи 2.

## Чего НЕ делать

- Не растягивать `RECONNECT_WINDOW_SECS` под время перезагрузки: окно
  возобновления — про сеть, а не про ребут, и его длина завязана на гранты.
- Не переносить автозапуск в `HKLM` и не превращать его в службу.
- Не переподключаться автоматически к устройствам, которые пользователь не
  пометил доверенными.
- Не сохранять гранты «на после перезагрузки».
- Не делать «выключить» без отдельного предупреждения.

## Definition of done

- `cargo test --workspace` зелёный: тест «после разрыва дольше окна гранты не
  восстанавливаются», тест отказа `RebootRequest` без гранта, тест отмены
  перезагрузки хостом.
- Вектор нового сообщения — в конец, старые не тронуты.
- `cargo clippy --workspace --all-targets -- -D warnings` — чисто.
- Настоящая проверка: хост перезагружен из интерфейса гостя; гость сам
  дождался и вошёл по паролю устройства; список того, что не пережило
  перезагрузку, — в отчёте.
- Проверено, что без доверенного устройства автоповтор не запускается.

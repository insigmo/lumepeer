# Пачка 07 — Гостевая личность клиента и перенос гостевых хранилищ

**Репозиторий:** lumepeer · **Зависит от:** 03 · **Нужно:** этот ПК и второй
узел-хост, который доверяет этой машине как гостю

Прочитать до начала: ADR 0169 §3 и «Consequences», ADR 0123 §5, ADR 0120,
ADR 0128 (как macOS хранит секреты в файлах профиля). Код:
`apps/desktop/src-tauri/src/placement.rs` (ветка «повышенный запуск» и
«профиль»), `crates/net/src/keystore*`, `crates/core/src/address_book.rs`
(`is_trusted(&NodeId)`), история и запомненные пароли
(`history_*`, `remembered`), `crates/net/src/endpoint.rs`.

## Задачи

### 1. Раскладка для клиента без прав на Windows

Новая ветка `placement.rs`: клиент, когда хостом машины является
session-host, держит **гостевые** хранилища в профиле — гостевая личность
(свой ключ эндпоинта, Credential Manager), список запомненных хостов,
пароли, запомненные для других хостов. Хостовых хранилищ у него нет вовсе.
Документ-комментарий модуля — обновить: какая ветка за что отвечает и почему
(ADR 0169 §3).

### 2. Однократный перенос

При первом подключении клиента к каналу (пачка 03) session-host отдаёт
клиенту гостевую часть из админского дерева **одним сообщением канала
«чтение»** — список запомненных хостов и запомненные для них пароли — и
удаляет её из админского дерева после подтверждения клиента. Хостовая часть
(личность, пароль устройства, адресная книга с доверенными устройствами,
приглашение, аудит) не двигается. Сообщение — в перечне чтения пачки 03, оно
ничего не расширяет: это данные самого пользователя о других машинах.

### 3. Новая гостевая личность

Клиент создаёт новый ключ при первом запуске в этой раскладке. Хосты,
которые доверяли этой машине как гостю, видят новый ключ: один ввод пароля
устройства там восстанавливает доверие. В клиенте при первой неудаче
доверенного входа после переноса — понятная подсказка «этот компьютер
получил новый ключ гостя — введите пароль один раз».

## Чего не делать

- Не давать клиенту ключ хоста ни копией, ни через «подпись по запросу» —
  два эндпоинта с одним ключом дерутся за relay и DHT.
- Не гнать гостевые сессии через session-host (разбор чужих медиа — на
  уровне пользователя, ADR 0169 §3).

## Definition of done

- [ ] После переноса клиент без прав видит все прежние сохранённые хосты и
      входит к ним с запомненными паролями.
- [ ] Админское дерево больше не содержит гостевой части; хостовая — на
      месте, гости этой машины входят как раньше.
- [ ] Хост, доверявший машине как гостю: первый вход — пароль и подсказка,
      второй — без пароля.
- [ ] Клиент и session-host одновременно онлайн с разными ключами, оба
      достижимы (лог relay без вытеснения).
- [ ] Повышенный `cargo test`, `npm test`, `fmt`, `clippy`.

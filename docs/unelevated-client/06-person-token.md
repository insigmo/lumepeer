**Репозиторий:** lumepeer · **Зависит от:** 02 · **Нужно:** этот ПК; гость
(`beta` или локальный второй экземпляр)

Прочитать до начала: ADR 0169 §6, ADR 0079, ADR 0102, ADR 0075, ADR 0076,
ADR 0124, ADR 0077/0078 (манифесты, туннель). Код:

## Задачи

### 1. Токены человека в session-host

Один модуль: токен консольного пользователя (`WTSQueryUserToken`) и его
повышенная половина (`TokenLinkedToken`; для вызывающего с TCB это
первичный токен — пачка 01 это измерила). Обновляется при смене
пользователя консоли; на экране входа (логон-хост) токена нет — операции,
которым он нужен, отвечают отказом, как сейчас на экране входа.

### 2. Терминал

Session-host запускает `lumepeer-terminal-worker` **ограниченным** токеном
пользователя через `CreateProcessAsUserW` (у `LocalSystem` есть
`SeAssignPrimaryToken`/`SeIncreaseQuota`). ADR 0079 и ADR 0102 не меняются:
оболочка — от человека, средний уровень. Ветку «токен Проводника +
`CreateProcessWithTokenW`» оставить для dev-прогона клиента в процессе.

### 3. Файлы

Каждая файловая операция хоста (листинг, чтение, запись, переименование,
удаление, приём файла от гостя) идёт в `spawn_blocking` под
`ImpersonateLoggedOnUser` с **повышенной** половиной, если она есть
(это ровно права нынешнего повышенного клиента), иначе — с ограниченным
токеном. Имперсонация снимается в том же потоке (guard с `RevertToSelf` в
`Drop`), никогда не «течёт» в пул tokio. Созданные файлы принадлежат
пользователю, а не `SYSTEM` (проверить владельца).

### 4. Запись и экспорт

Экспорт записи — в папку пользователя под его токеном (как файлы). Где
лежат записи хоста — оставить, где они сейчас в админском дереве; список и
экспорт клиент получает через канал пачки 03 (чтение).

### 5. Туннель

Остаётся подключением от session-host — сказать это в doc-комментарии
модуля туннеля со ссылкой на ADR 0169 §6.

## Чего не делать

- Не выполнять файловые операции от `SYSTEM` «потому что так проще» — гость
  с `file_browse` получил бы больше, чем имеет человек за машиной.
- Не запускать оболочку повышенной половиной.

## Definition of done

- [ ] Терминал гостя на хосте-session-host: `whoami` — пользователь,
      `whoami /groups` — Medium Mandatory Level.
- [ ] Файловый менеджер видит то же, что видел повышенный клиент (папка
      только для администраторов — читается у админа, не читается у
      стандартной учётки).
- [ ] Принятый от гостя файл — владелец пользователь (`icacls`/`Get-Acl`).
- [ ] Экспорт записи лежит в папке пользователя, владелец — пользователь.
- [ ] Повышенный `cargo test`, `npm test`, `fmt`, `clippy`.

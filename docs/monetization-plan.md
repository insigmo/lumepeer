# План монетизации Lumepeer

Дата: 2026-10-19. Основание: код `master` на `v0.0.155` (`2e38d03`),
`docs/comparison-rustdesk-teamviewer-anydesk.md` (от 2026-09-08, частично
устарел — logon host, файловый менеджер, терминал, туннель и звук на macOS
с тех пор появились). Цены конкурентов здесь не приводятся: перед запуском
их нужно проверить на их сайтах.

Цель: продавать всем, кому можно, но заходить в сегменты по очереди — туда,
где деньги приходят быстрее и где один сегмент приводит следующий.
AI Support (`docs/ai-support/`) — позже, отдельным треком.

---

## 0. Что для денег уже есть в коде

| Есть | Где | Состояние |
|---|---|---|
| Формат лицензионного токена, Ed25519, `verify_strict` | `crates/core/src/license.rs` | готов |
| Планы `Trial` / `Pro` / `Team` | там же, `constants.rs` | Trial = **30 минут суммарно**, Pro = 1 гость, Team = 5 |
| Лимит гостей по плану | `SessionManager::with_plan` | работает, но приложение всегда стартует как `Trial` |
| Брокер: выдача лицензии, webhook оплаты (подпись, окно 5 мин, защита от replay) | `services/broker` | написан; к реальному платёжному провайдеру не подключён |
| Статус лицензии в UI | `license_status` в `commands.rs` | **заглушка** («Phase 3 fills these…») |

Вывод: продавать сегодня технически нечем — нет ни кнопки «Купить», ни
проверки токена в приложении. Это и есть первый этап.

**Обновление 2026-10-19:** проверка токена, клиент брокера, план `Free` и
панель лицензии в приложении сделаны — ADR 0163 (этап 1, пункт 3).

**Конфликт с планом ниже:** `Trial` в коде — 30 минут на всё время. Для охвата
нужен бесплатный личный тариф без ограничения по времени. Решение за
владельцем (см. §6).

## 1. Сегменты и порядок захода

1. **Эникейщики, фрилансеры, маленький ИТ-аутсорс.** Платят сразу со своей
   карты, ценность понимают без объяснений, каждый ставит Lumepeer своим
   20–200 клиентам. Это и деньги, и канал в сегмент 2.
2. **Частники и семьи.** Приходят через клиентов техников и через «поставь
   маме». Покупают защиту от мошенников, а не удалённый доступ.
3. **Компании.** Самые крупные чеки, самый длинный цикл. Требуют MSI/GPO,
   консоль, договоры; в РФ — реестр отечественного ПО.

Одно обещание на сегмент, на лендинге — три блока:

| Сегмент | Обещание |
|---|---|
| Техник | «Дешевле TeamViewer, без “commercial use detected”, без блокировок, с отчётом для клиента» |
| Семья | «Мошенник не сможет управлять компьютером мамы» |
| Компания | «Никаких серверов вендора и глобальных ID — нечего взломать, нечего перебрать» |

## 2. Тарифы

| Тариф | Кому | Что даёт | Оплата |
|---|---|---|---|
| Free | личное | 1 гость, без лимита времени, все базовые функции | 0 |
| Семья | частники | + защита от мошенников, доверенные устройства семьи | раз в год |
| Pro | техник | + unattended, отчёт клиенту, терминал, файлы, туннели, без ограничений числа хостов | помесячно / год |
| Team | аутсорс, компании | + 5+ техников, общая адресная книга, развёртывание, позже консоль | за техника |

Ориентир — примерно половина цены AnyDesk/TeamViewer за сопоставимый тариф:
своих серверов нет, себестоимость почти нулевая, низкая цена маржу не ест.

Добавить `Free` и `Family` в `Plan` — дописать варианты в хвост (правило
минорной версии), `from_wire_or_trial` уже безопасно откатывает незнакомый
байт к наименьшим правам.

## 3. Этапы

Каждый пункт заканчивается проверяемым «готово».

### Этап 1 — «можно заплатить» (первым делом)

1. **Подпись установщиков.** Authenticode на Windows, Developer ID +
   нотаризация на macOS (сейчас — самоподписанный сертификат, ADR 0128).
   Деньги и бумаги, не инженерия.
   *Готово:* чистая Windows 11 ставит релиз без предупреждения SmartScreen;
   чистый Mac открывает без обхода Gatekeeper.
2. **Платёжные провайдеры.** Два контура: РФ (ЮKassa или аналог) и
   международный (Paddle или Lemon Squeezy — merchant of record, НДС платят
   они). Webhook брокера уже ждёт подписанное событие.
   *Готово:* тестовая оплата в sandbox каждого провайдера выдаёт токен.
3. **Лицензия в приложении.** *Сделано — ADR 0163; оживает после деплоя
   брокера и `LUMEPEER_BROKER_URL` / `LUMEPEER_BROKER_PUBLIC_KEY` в релизной
   сборке.* Ввод/получение токена, проверка, реальный
   `license_status`, план передаётся в `SessionManager`, heartbeat и offline
   grace по §12.
   *Готово:* приложение с токеном Pro пускает unattended, без токена — Free.
4. **Лендинг RU + EN** с тремя обещаниями из §1 и кнопкой «Купить».
   *Готово:* путь «лендинг → оплата → токен в приложении» проходит руками
   за 2 минуты.

### Этап 2 — то, за что платит техник (Pro)

5. **Отчёт клиенту после сессии.** Собирается из уже существующего:
   аудит-лог (`crates/core/src/audit.rs`), гранты сессии, передачи файлов,
   команды терминала (если терминал был), длительность. Подписывается ключом
   устройства, открывается как HTML/PDF, отправляется клиенту одной кнопкой.
   Хост видит, что отчёт формируется (в духе A8 — согласие обеих сторон).
   *Готово:* после сессии у техника есть файл, который проверяется подписью
   и в котором перечислено всё, что было сделано.
6. **Гость с Android.** Только гость (смотреть и управлять), без хоста.
   Первым делом спрашивают именно это.
   *Готово:* телефон подключается к Windows-хосту по инвайту и управляет им.

### Этап 3 — то, за что платит семья

7. **Защита от мошенников, v1.**
   - Окна банков, Госуслуг, менеджеров паролей на хосте закрываются для гостя
     чёрным прямоугольником (список приложений + правила по заголовку окна).
   - Незнакомый пир первые N минут получает только просмотр; ввод — после
     явного подтверждения с крупным предупреждением «Вас просят открыть банк
     или продиктовать код? Это мошенники».
   - Режим «семья»: подключаться могут только доверенные устройства,
     остальные отклоняются без диалога.
   *Готово:* e2e-тест: при открытом банковском окне гость получает чёрный
   прямоугольник; незнакомый пир не может ввести ни символа до подтверждения.

### Этап 4 — компании (Team)

8. **MSI и тихая установка** с предконфигурацией (GPO/Intune).
9. **Простая консоль устройств** для Team — без облака вендора: общая
   адресная книга техников.
10. **Реестр отечественного ПО** (если продаём в РФ госсектору и крупным
    компаниям) — бумаги.

### Параллельно с этапами 1–3

- **Интерфейс** — §4.
- **Скиллы для Claude** — §5.

### Позже

- **AI Support** — по `docs/ai-support/`, становится главной функцией Pro.

## 4. Интерфейс: красиво, просто, функционально

Принцип: на главном экране и в панели сессии — только то, что нужно в
каждой второй сессии. Всё, что требует понимать, как устроено видео или
сеть, — в настройки, раздел «Дополнительно».

### Шаг 1 — аудит на живом экране

Пройти главное окно, окно просмотра, панель хоста, файловый менеджер,
терминал и настройки в превью (`npm run dev` + мок `__TAURI_INTERNALS__`)
на светлой и тёмной теме, по сценарию «новичок впервые подключается» и
«техник в 20-й сессии за день». Результат — таблица «элемент → оставить /
перенести / убрать / переписать текст».

### Кандидаты на перенос (гипотезы, проверить в аудите)

Из меню настроек панели сессии (`toolbar.ts`) в «Дополнительно»:

| Сейчас в панели | Почему мешает |
|---|---|
| Выбор энкодера | пользователь не знает, что такое AV1 и аппаратный энкодер |
| Режим отображения / разрешение хоста и предупреждение о нём | нужно раз в жизни |
| Встроенный / локальный курсор | техническая деталь, разумная по умолчанию |

В панели остаются: качество (одним ползунком «чётче ↔ быстрее»), мониторы,
полноэкранный режим, файлы, чат, терминал, Ctrl+Alt+Del, отключиться.

Тексты: сообщения об ошибках подключения (`invite.*`) переписать на «что
случилось + что нажать», без внутренних терминов.

### Шаг 2 — переделка

Через `impeccable` (polish / simplify) по таблице аудита, по одному экрану
за раз, со скриншотами до/после.
*Готово:* новичок проходит «установил → подключился → передал файл» без
подсказок; на главном экране нет ни одного технического термина.

## 5. Скиллы для Claude

Понимается так: скиллы Claude Code в `.claude/skills/` репозитория, чтобы
агент не наступал на одни и те же грабли при разработке Lumepeer.
(Альтернатива — «Claude управляет Lumepeer» как функция продукта — уходит
вместе с AI Support «на потом».)

Сейчас там пустой `.claude/skills/my-skill/`. Кандидаты, каждый закрывает
повторявшиеся ошибки:

| Скилл | Что внутри |
|---|---|
| `lumepeer-e2e` | матрица `e2e/matrix` (win / beta / mac / linux), tauri-pilot, ловушки стенда, которые выглядят как баги приложения |
| `lumepeer-windows-tests` | запуск тестов с повышением (RunAs), RunAsInvoker для тестовых бинарников, сайдкары в `binaries/`, тесты без capture-бэкенда по умолчанию |
| `lumepeer-linux-build` | сборка в WSL Debian, `/root/lp-target`, что можно и что нельзя на debian-VM |
| `lumepeer-mac` | доступ к Mac-VM через beta, BlackHole, TCC/Accessibility, подпись |
| `lumepeer-adr` | как взять следующий свободный номер ADR и формат записи |
| `lumepeer-ipc-command` | новая Tauri-команда: `commands.rs`, `main.rs`, `build.rs` COMMANDS, capability |
| `lumepeer-release` | `docs/release-checklist.md` как исполняемая процедура |
| `lumepeer-ui-preview` | главное окно в превью браузера с моком IPC, ловушки HMR |

*Готово:* для каждого скилла — короткий `SKILL.md` + проверка на одной
реальной задаче, что агент проходит её без старых ошибок.

## 6. Решения за владельцем

1. **Free без лимита времени или Trial 30 минут?** Рекомендация — Free для
   личного использования без лимита: охват важнее, а платят за unattended,
   отчёт и защиту.
2. **Юрлицо и платёжные контуры** для РФ и для остального мира.
3. **Сертификаты подписи** — какой поставщик Authenticode, аккаунт Apple
   Developer.
4. **Нужен ли реестр отечественного ПО** — только если идём в госсектор.
5. **Цены** — после проверки текущих цен конкурентов.

## 7. Как понять, что работает

- Конверсия «скачал → установил» (видно после подписи установщиков).
- Конверсия «Free → Pro» у техников и «Free → Семья» у частников.
- Сколько новых установок приходит с хостов, на которых уже стоит Lumepeer
  (метка «Защищено Lumepeer» / реферальный код в инвайте).
- Отток Pro по месяцам.

# Пачка 09 — macOS: ремонт и безопасность

**Репозиторий:** support_knowledge · **Зависит от:** 02 (01 — версии и
объём проверок) · **Нужно:** доступ в веб; macOS ВМ — желательно (у
владельца есть Mac-ВМ на машине `beta`, см. память проекта)

Перед началом — `content-workflow.md`, `contracts.md` § 3,
`research/security-assessment.md`. Каталог: `knowledge/macos/<area>/`.
Версии — поддерживаемые Apple ветки по матрице 01; отличия Apple silicon и
Intel — внутри документа таблицей, отдельный документ только при разных
процедурах (Recovery, загрузка). Текст Apple Support не копируется —
своими словами со ссылкой.

## Ремонт (по убыванию приоритета)

### Загрузка и восстановление (`boot`)

1. Как попасть в macOS Recovery и безопасный режим (Apple silicon / Intel)
   — справочный, на него ссылаются остальные и пачка 18.
2. Не загружается: серый экран, знак «запрещено», папка с вопросом,
   циклическая перезагрузка — диагностика по порядку.
3. Переустановка macOS **с сохранением данных** из Recovery — когда
   оправдана; чем отличается от стирания.
4. Дисковая утилита: Первая помощь (First Aid) для тома/контейнера — что
   делает и чего не делать (стирание).

### Обновления (`updates`)

5. Обновление не скачивается/не устанавливается — место, сеть,
   `softwareupdate --list`, журнал установки.

### Место и производительность (`storage`, `performance`)

6. «Системные данные» занимают много — локальные снимки Time Machine
   (`tmutil listlocalsnapshots`), кэши, журналы; безопасная очистка.
7. Mac тормозит / шумит — Мониторинг системы, `kernel_task` (перегрев),
   индексирование Spotlight (`mds`), процессы с утечкой.

### Сеть и устройства (`network`, `bluetooth`, `audio`, `display`, `peripherals`)

8. Wi-Fi подключён, интернета нет / DNS — «Забыть сеть», DNS-серверы,
   прокси, профили конфигурации; встроенная «Беспроводная диагностика».
9. Bluetooth-устройства отваливаются/не подключаются.
10. Нет звука — устройство вывода, `coreaudiod` (перезапуск требует прав),
    приложения-аудиодрайверы (виртуальные устройства).
11. Внешний монитор не определяется / неправильное разрешение (USB-C/
    Thunderbolt, адаптеры, ограничения числа мониторов у чипа).
12. Принтер не печатает — удалить/добавить, сброс системы печати (как
    `dangerous` с последствиями).

### Приложения и разрешения (`apps`, `accounts`)

13. «Приложение повреждено и не может быть открыто» / «неустановленный
    разработчик» — Gatekeeper и атрибут карантина: **как безопасно**
    (проверить источник, открыть через контекстное меню/настройки);
    `xattr -d com.apple.quarantine` — только с предупреждением и только для
    приложения из доверенного источника.
14. Разрешения конфиденциальности (TCC): запись экрана, универсальный
    доступ, микрофон, полный доступ к диску — где включить, почему
    приложение «не видит» разрешение после обновления (переподписанное
    приложение), `tccutil reset` как крайняя мера. Важно и для самого
    Lumepeer.
15. Приложение падает — отчёты о сбоях, сброс настроек приложения
    (резервная копия plist).
16. Time Machine не делает копии — диск, место, права, исключения.
17. Связка ключей постоянно запрашивает пароль — официальные шаги, без
    удаления связки по умолчанию.

## Безопасность

### Документ на каждую macOS-проверку (`security_check`)

Каждый `mac.*` id из `contracts.md` § 3. Особо:

- `mac.update.os_version` — сравнение версии с последней для своей
  мажорной ветки по эталону (пачка 13); Rapid Security Responses / фоновые
  обновления безопасности — проверить, как они называются в текущих
  версиях.
- `mac.os.support_status` — Apple не публикует EOL официально; честно
  описать, на чём основана оценка (какие ветки получают обновления), и
  что тогда `confidence` не `high`.
- `mac.sharing.remote_login` — без прав администратора читать по
  слушающему порту 22 / состоянию `launchd`, а не `systemsetup` (требует
  админа).
- `mac.firewall` — выключенный файрвол на Mac по умолчанию — норма;
  severity с учётом открытых служб, а не «critical».

### Угрозы

18. Подозрение на вредонос — XProtect и встроенные механизмы, элементы
    входа и LaunchAgents/LaunchDaemons (как оценить подпись и путь),
    подозрительные профили конфигурации (MDM-профили как способ угона
    браузера/прокси).
19. Угон браузера (поисковик, расширения, профили) — безопасное удаление.

## Чего НЕ делать

- Не советовать отключать SIP, Gatekeeper (`spctl --master-disable`) как
  решение; не советовать сторонние «чистильщики» Mac.
- Не писать о хакинтошах, OpenCore Legacy Patcher как способе продлить
  поддержку (риски) — максимум упоминание в `support_status` с
  предупреждением.
- Не копировать статьи Apple Support.

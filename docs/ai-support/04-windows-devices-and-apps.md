# Пачка 04 — Windows: устройства, звук, видео, приложения, учётки, BSOD

**Репозиторий:** support_knowledge · **Зависит от:** 02 · **Нужно:** доступ в
веб; ВМ Windows 11 — желательно

Перед началом — `content-workflow.md`. Каталог: `knowledge/windows/<area>/`.
Если пачка 03 уже влита — ссылаться на её справочные документы (WinRE,
System Restore), не повторять.

## Темы (по убыванию приоритета)

### Звук (`audio`)

1. Нет звука — общий плейбук: устройство по умолчанию, отключённое
   устройство, служба `Audiosrv`/`AudioEndpointBuilder`, драйвер,
   эксклюзивный режим, улучшения звука.
2. Микрофон не работает — сначала настройки конфиденциальности
   (доступ приложений к микрофону), потом устройство и драйвер.
3. Звук через HDMI/DisplayPort/USB-гарнитуру не переключается.

### Видео и дисплей (`display`)

4. Сбой видеодрайвера (TDR), события `nvlddmkm`/`amdkmdag`/`igfx`, мерцание
   — откат и чистая установка драйвера **с сайта вендора GPU или через WU**;
   DDU — только как анти-паттерн-оговорка (риски), не шаг по умолчанию.
5. Второй монитор не определяется, неправильное разрешение/частота,
   масштаб.
6. HDR выглядит блёклым / цвета неправильные.

### Устройства (`peripherals`, `bluetooth`)

7. USB-устройство не распознано / Code 43 / Code 10 — диспетчер устройств,
   питание USB, драйвер.
8. Bluetooth: устройство не подключается, адаптер пропал, звук через BT
   прерывается.
9. Принтер «Offline» / задания зависли — спулер (действие
   `print.clear_queue`), драйвер, порт.
10. Камера не найдена / чёрный экран — конфиденциальность, переключатель
    на корпусе, драйвер, занятость другим приложением.
11. Клавиатура/мышь/тачпад: залипание, фильтрация ввода, драйвер тачпада.

### Приложения и службы (`apps`, `services`)

12. Приложение падает при запуске — журнал Application (событие 1000/1026),
    отсутствующие Visual C++ / .NET, совместимость; где чинить, а где
    переустанавливать.
13. Microsoft Store не открывается / не скачивает — `wsreset`, служба,
    перерегистрация (с рисками).
14. Меню «Пуск» / поиск / панель задач не работает; Проводник
    перезапускается.
15. Программа не удаляется — официальное средство Program Install and
    Uninstall troubleshooter, а не ручная правка реестра.
16. Служба не запускается: коды ошибок SCM (1053, 1068, 1069), зависимости.

### Учётные записи и доступ (`accounts`)

17. Вход во временный профиль («You've been signed in with a temporary
    profile») — диагностика ProfileList с резервной копией ключа.
18. PIN / Windows Hello перестал работать — сброс через параметры; папка
    Ngc — с рисками.
19. «Access is denied» к файлам и папкам — права, владелец; смена владельца
    как `dangerous` со способом вернуть исходные ACL (`icacls /save`).
20. Забытый пароль — только официальные пути (учётная запись Microsoft,
    контрольные вопросы, другой администратор). Никаких обходов.

### Падения системы (`crashes`)

21. BSOD — как читать код и параметры (журнал, minidump, `WhoCrashed` и
    подобные сторонние — нет; встроенные средства), общий порядок.
22. Частые коды: `MEMORY_MANAGEMENT`, `IRQL_NOT_LESS_OR_EQUAL`/
    `DRIVER_IRQL_NOT_LESS_OR_EQUAL`, `CRITICAL_PROCESS_DIED`,
    `WHEA_UNCORRECTABLE_ERROR`, `KERNEL_SECURITY_CHECK_FAILURE` — один
    документ на код только если диагностика реально разная, иначе — один
    документ с таблицей.
23. Внезапные перезагрузки без BSOD (Kernel-Power 41) — питание,
    перегрев, драйвер.

### Время

24. Неправильное время / ошибки сертификатов из-за времени — `w32time`,
    действие `time.resync`.

## Чего НЕ делать

- Не повторять темы пачки 03 (загрузка, обновления, сеть, диски,
  производительность) и 05 (безопасность).
- Не советовать сторонние «driver updater», загрузку драйверов с
  агрегаторов, взломанные утилиты.
- Не писать о разгоне, BIOS-модификациях, перепрошивке.
- Не писать по одному документу на каждую модель принтера/камеры.

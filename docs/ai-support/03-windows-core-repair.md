# Пачка 03 — Windows: загрузка, обновления, сеть, диски, производительность

**Репозиторий:** support_knowledge · **Зависит от:** 02 · **Нужно:** доступ в
веб; ВМ Windows 11 — желательно для `verified`

Перед началом — `content-workflow.md` целиком. Версии: Windows 11 (23H2,
24H2 и новее — по матрице 01) и Windows 10 22H2 (с пометкой о статусе
поддержки). Каталог: `knowledge/windows/<area>/`.

## Темы (по убыванию приоритета)

### Загрузка и восстановление (`boot`)

1. Цикл «Automatic Repair» / «Preparing Automatic Repair» — диагностика из
   WinRE, журнал `SrtTrail.txt`, безопасные шаги.
2. Как попасть в WinRE и безопасный режим, когда Windows не грузится
   (справочный, на него ссылаются остальные).
3. Ошибки загрузчика: `BOOTMGR is missing`, `0xc000000e`, `0xc0000225`,
   повреждённый BCD — диагностика, `bootrec`/`bcdboot` с рисками и
   откатом (экспорт BCD до изменений).
4. `INACCESSIBLE_BOOT_DEVICE` после обновления/смены режима контроллера.
5. Запрос ключа восстановления BitLocker при загрузке — где взять ключ
   (официальные пути), почему появился, чего не делать.
6. Чёрный экран после входа / после обновления.
7. Восстановление системы (System Restore) из WinRE — справочный
   документ, на который сошлётся пачка 18.

### Обновления (`updates`)

8. Windows Update не устанавливает обновления — общий плейбук:
   `0x80070002`, `0x8024402c`, `0x80244022`, `0x800f0922` и т. п.;
   сброс компонентов WU (с откатом: переименование, а не удаление папок).
9. Повреждённое хранилище компонентов: `0x800f081f`, `0x80073712` — DISM
   `/CheckHealth` → `/ScanHealth` → `/RestoreHealth`, SFC; порядок и что
   каждая команда меняет.
10. Цикл «Undoing changes» / «We couldn't complete the updates».
11. Удаление проблемного обновления (KB), пауза обновлений; что нельзя
    удалить (SSU).
12. Обновление компонентов (feature update) блокируется: compatibility
    hold, нехватка места, драйвер.

### Сеть (`network`)

`windows.network.dns-resolution` уже есть (пачка 02) — не повторять,
ссылаться.

13. «No Internet, secured» / «Нет подключения к Интернету» при рабочем
    Wi-Fi: NCSI, прокси, DNS, адрес APIPA `169.254.x.x`.
14. Wi-Fi-сеть не видна / адаптер пропал / «Wi-Fi turned off» — драйвер,
    служба WLAN AutoConfig, режим «в самолёте», управление питанием.
15. Ограниченное подключение / «Unidentified network» по Ethernet.
16. Сброс сети (Network reset) и `netsh winsock reset`/`int ip reset` —
    когда оправдано, последствия (VPN-адаптеры, нужна перезагрузка).
17. VPN ломает интернет или DNS после отключения (раздельное
    туннелирование, оставшиеся маршруты/DNS).
18. Подмена прокси и файла hosts (часто — следы вредоносного ПО или
    «оптимизаторов»): диагностика и безопасное восстановление.
19. Нет доступа к общим папкам/NAS в локальной сети: обнаружение сети,
    профиль сети, SMB-клиент — **без** включения SMB1.

### Диски и место (`storage`)

20. Мало места на диске C: — безопасный порядок: Storage Sense / Disk
    Cleanup, `WinSxS` через DISM `/StartComponentCleanup`, гибернация,
    точки восстановления; чего не удалять руками.
21. Диск загружен на 100% — диагностика по процессу (поиск, WU, антивирус,
    SysMain), признаки умирающего диска.
22. Признаки отказа накопителя (SMART, события `disk`/`Ntfs`, ошибки
    чтения) — **сначала резервная копия**, потом проверки; `chkdsk` и его
    риски.
23. Диск не отображается в Проводнике — буква, инициализация (явно:
    инициализация/форматирование стирает данные — только справка, не шаг
    по умолчанию).

### Производительность (`performance`)

24. Медленная загрузка и вход — автозапуск, службы, быстрый запуск,
    диагностика по журналу Diagnostics-Performance.
25. Высокая загрузка CPU системными процессами: `Antimalware Service
    Executable`, `Windows Search`, `svchost` (WU/DO), `System interrupts` —
    как определить причину, а не «отключить».
26. Нехватка памяти / постоянный своп / утечка в процессе — commit charge,
    файл подкачки.
27. Перегрев и троттлинг ноутбука, план электропитания.

## Чего НЕ делать

- Не писать о звуке, видео, устройствах, приложениях, учётных записях,
  BSOD — это пачка 04; безопасность — 05.
- Не советовать сторонние «оптимизаторы», чистильщики реестра, ручное
  удаление `WinSxS`, `System32`-файлов, отключение Защитника или
  обновлений навсегда.
- Не писать инструкции по активации/обходу лицензий Windows и обходу
  требований к железу Windows 11.
- Не дублировать один и тот же сброс WU в нескольких документах:
  один документ, остальные ссылаются.
- Не придумывать коды ошибок для полноты.

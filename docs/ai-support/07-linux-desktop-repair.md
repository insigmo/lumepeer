Перед началом — `content-workflow.md`. Каталоги как в пачке 06. Учитывать
окружения рабочего стола по матрице 01 (обычно GNOME, KDE Plasma, Cinnamon)

## Темы (по убыванию приоритета)

### Звук (`audio`)

1. Нет звука — PipeWire/WirePlumber (`wpctl status`, `systemctl --user`),
   выбор профиля карты, приглушённый канал (`alsamixer`), ещё живой
   PulseAudio.
2. Микрофон не работает / не тот вход; разрешения портала в Flatpak.
3. HDMI/USB/Bluetooth-аудио не переключается, треск/рассинхрон (квант,
   частота дискретизации — справочно, без «тюнинга» по форумам).

### Видео (`display`)

4. NVIDIA: чёрный экран/откат на nouveau после обновления ядра — модуль
   не собран (DKMS/akmods), Secure Boot и подпись модуля (MOK), версии
   драйвера по семействам.
5. Wayland vs X11: приложение не работает/не видит экран, запись экрана и
   демонстрация (порталы xdg-desktop-portal) — как переключить сеанс.
6. Второй монитор, масштаб, дробное масштабирование, частота.
7. Экран тормозит/рвётся — аппаратное ускорение, драйвер Mesa.

### Bluetooth (`bluetooth`)

8. Адаптер не виден / не включается — `rfkill`, `bluetoothctl`, служба,
   прошивка.
9. Устройство не сопрягается / отваливается; наушники только в «гарнитуре»
   (профили A2DP/HFP с PipeWire).

### Wi-Fi и драйверы (`network`)

10. Wi-Fi-адаптер не работает: нет прошивки (`linux-firmware`), модуль
    драйвера, Broadcom/Realtek-особенности по семействам; `rfkill`.
11. Wi-Fi часто отваливается — энергосбережение адаптера, регион, MAC
    randomization.

### Печать и сканирование (`peripherals`)

12. Принтер не печатает — CUPS (`lpstat`, веб-интерфейс), driverless IPP
    Everywhere, очередь (`print.clear_queue`).
13. Сканер не виден — SANE/eSCL.

### Приложения (`apps`)

14. Flatpak-приложение не видит файлы/устройства — порталы и разрешения
    (`flatpak override`, Flatseal — справочно).
15. Snap: медленный запуск, обновления, удаление старых ревизий; Firefox
    как snap в Ubuntu.
16. Приложение падает — запуск из терминала, `coredumpctl`, отсутствующие
    библиотеки.
17. Игры/Steam: Proton не запускает игру — справочно общий порядок (логи
    Proton, версия), если матрица 01 даёт игровой аудитории P1/P2.

### Вход в систему (`accounts`)

18. Цикл входа (логин → снова экран входа) — права на `~/.Xauthority`/
    `~/.cache`, заполненный диск, сломанный драйвер.
19. Не запускается графическая оболочка — переход в TTY, журнал
    дисплей-менеджера.

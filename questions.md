### Не успел / заблокировано

1. **E2E на VM упирается в таймауты tauri-pilot eval.** Приложение живёт,
   `tauri-pilot ping/windows` работают, но любой eval-шаг падает по 10 c:
   колбэк `plugin:pilot|__callback` не возвращается из страницы. Локально
   добавил `remote.urls` в capability (devUrl — это http://localhost:5173),
   не помогло. Следующий шаг: либо поднимать vite dev server на VM, либо
   собирать с встроенным frontendDist (production URL), либо разбираться с
   версий плагина/CLI. На это ушёл остаток времени.
2. **Wayland-E2E не запускался** — заблокирован тем же пунктом; сессия
   cinnamon-wayland на .130 подтверждена (WAYLAND_DISPLAY=wayland-0),
   скрипт уже умеет её находить.
3. **Захват/воспроизведение аудио** — сделан только кодек; WASAPI/PipeWire/
   CoreAudio-захват и продакшн-проводка AudioStart/AudioStop через net — нет
   (см. новые вопросы №8–9).
4. **Интеграция записи** — формат готов, но писатель не включён в живой
   конвейер (нет UI-переключателя и вызова с проверкой гранта `recording`).
5. **Чат в основном окне хоста** — панель пока только в окне просмотра
   (гостевая сторона).

## Текущие открытые вопросы

### 8. Аудио-захват: какой backend брать для каждой ОС?
Кодек готов (Opus, `audio-opus`), но остался захват самого звука: WASAPI
loopback (Windows), PipeWire/PulseAudio monitor (Linux), CoreAudio tap
(macOS). Кандидаты: `cpal` против платформенных API напрямую за фичами.
**Предлагаю:** `cpal` за фичей `audio-capture`.

### 9. Воспроизведение у гостя: cpal или через decoder-worker?
Декодирование видео вынесено в sandbox-процесс (§11.3). Звук можно декодировать
там же и отдавать PCM по ring buffer, воспроизводя в главном процессе.
**Предлагаю:** так и сделать — sandbox остаётся единственным местом обработки
недоверенного битстрима.

## Решённые вопросы

### 1. Аудио: какой кодек Opus-крейт брать в воркспейс? — **решено 2026-08-22**
Крейт `opus = "0.3"` (биндинги над libopus), системный SDK не нужен:
`audiopus_sys` вендорит исходники и собирает cmake'ом — тот же прецедент, что
openh264. Фича `audio-opus`; без неё аудио-точки отказывают громко.
Константы: 48 кГц, стерео, 20 мс, 96 кбит/с. Потери → concealment.
ADR 0023. Сборочным хостам нужен cmake на PATH.

### 2. Unattended-пароль: argon2 или PBKDF2? — **решено 2026-08-22**
`argon2 = "0.5"` (RustCrypto), Argon2id; PHC-строка в OS keystore; проверка в
TCB; 5 неудач → lockout 300 с. Соль из workspace CSPRNG через
`SaltString::encode_b64`.

### 3. TOTP 2FA: самим или крейт? — **решено 2026-08-22**
Своя реализация RFC 6238 поверх HMAC-SHA1 (~50 строк) + тесты на векторах
Appendix B (последние 6 цифр опубликованных 8-значных). Окно ±1 шаг.

### 4. Приоритет платформ — **решено 2026-08-22**
Ядро → Windows → Linux → macOS; Wayland последним, отдельная Wayland-VM
(`WAYLANDLINUX_HOST`), E2E по SSH на обеих Linux-машинах.

### 5. Мобильные/web клиенты — **решено 2026-08-22**
Отложить до готовности десктопа.

### 6. Relay — **решено 2026-08-22**
Документация + docker-compose для self-host `iroh-relay`; своего кода релея
нет. Плюс клиентский override `LUMEPEER_RELAY_URL`. ADR 0023.

### 7. Запись сессии — **решено 2026-08-22**
Кастомный append-only контейнер «LMRC», MKV-экспорт позже. Заголовок + записи
(видео/Opus/JSON-события), относительные таймстампы, проверки до аллокации,
оборванный файл = валидный префикс. Грант `recording`. ADR 0023.
